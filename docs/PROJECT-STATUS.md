宽度/焦点交付中，受影响的两份 UI spec 共 96 个用例通过；随后最后一处选择器特异性修正通过 10 个相关用例。两者存在覆盖重叠，不能相加宣称 106 个独立用例，也不是一次全库测试。

最终候选和实际隧道各记录 24 个宽度/焦点状态；更早的 Radar 对齐另有个人/公开对照与真实语料证据。截图、API 替身、真实语料和真实外网各证明不同事情，说明见 [测试与证据指南](TESTING.md)。`tmp` 中的证据默认不随代码分发，发布记录应保留范围、结论和定位信息，而不外传个人数据。
